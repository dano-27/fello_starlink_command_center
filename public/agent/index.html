Setup Guide — Windows Agent
▼
  1. Install Node.js on Windows PC.
  2. Create a directory and install dependencies: npm init -y && npm install playwright ws
  3. Install Chromium: npx playwright install chromium
  4. Download the agent script (e.g. fello-agent.js) from the repository.
  5. Set environment variables:
    set AGENT_SERVER=wss://your-command-center-url
    set AGENT_SECRET=your_secret_key
    set SIMPLEMDM_EMAIL=email@example.com
    set SIMPLEMDM_PASSWORD=securepassword
  6. Run the agent: node fello-agent.js
