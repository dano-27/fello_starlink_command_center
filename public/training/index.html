🏠What is the Command Center?

How Devices Get Matched

iPads report Serial Numbers to MDM. SIMs report ICCIDs and IMEIs to the carrier. The Command Center bridges them:

1Pass 1: ICCID MatchMatches MDM eSIM subscriptions directly against Webbing SIM inventory
2Pass 2: ABM IMEI BridgeQueries Apple Business Manager for hardware IMEIs, matches against Webbing cellular modem IMEIs

📲 Fello Connect — Required Companion App

Fello Connect is Fello's custom iPad companion app that must be installed and running on every deployed iPad. It is the foundation for remote support capabilities.

What Fello Connect Does

  • Enables Screen Sharing — Powers the CoBrowse integration that lets you view and interact with an iPad's screen remotely from the Command Center
  • Reports GPS Location — Sends high-precision GPS coordinates back to the Command Center for the location map in the device drawer
  • Stays in Background — Designed to run silently in the background without interfering with the event app experience
  • Auto-Deployed — Automatically pushed to all iPads during provisioning as the default baseline app
⚠️ Screen Share will NOT work without Fello Connect installed and running on the iPad. If a screen share fails to connect, first verify the app is installed (check 📦 Managed Apps in the drawer), then try Push Apps from MDM Controls to force-install it.

Troubleshooting Screen Share

1Open the Device Drawer for the target iPad
2Check 📦 Managed Apps — verify "Fello Connect" appears in the list
3If missing, click Push Apps in 🔧 MDM Controls to install it
4Ensure the iPad is online (check SIM status is Active and battery > 0%)
5Click 📺 Screen in Quick Actions to launch the session
6If still failing, try 🔄 Restart to reboot the iPad remotely

🔄Common Workflows

🔄 Pre-Event: Prepare an Order

1Search the order number e.g., FE13916
2Check Coverage — review auto-generated site check, click Apply on best carrier
3Resume Service — click ▶ Resume Service in sidebar
4Verify — scan fleet table for any Suspended badges
5Pulse — copy generated share link, send to event organizer
6Export — download CSV for warehouse packing checklist

🛑 Post-Event: Decommission Equipment

1Search the order
2Suspend — click ⏸ Suspend Service Prevents idle data charges
3Lost Mode — click 🔴 with return message Secures iPads in transit
4Usage — set dates to rental period, click Calculate
5Export — download billing CSV
6Revoke — kill the Pulse share link

🆘 During Event: Troubleshoot a Device

1Search order or device serial
2Open Drawer — click the device row
3Diagnose: No connectivity → Check SIM Status, Resume if Suspended Wrong carrier → Change Carrier in SIM Controls App issue → Push Apps in MDM Controls Screen frozen → Remote Restart in Quick Actions Need to see screen → Verify Fello Connect is installed, then launch Screen Share via CoBrowse

📊 Billing: Generate a Usage Report

1Search the order in Lookup
2Confirm date range in 📊 Data Usage sidebar card
3Click 📊 Calculate
4Review total GB and active lines
5Click 📥 Export CSV to download
