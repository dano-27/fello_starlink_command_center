🏠What is the Command Center?

The Fello Command Center is a unified operations platform that brings together six core systems into one dashboard. One search pulls everything together.

How Devices Get Matched

iPads report Serial Numbers to MDM. SIMs report ICCIDs and IMEIs to the carrier. The Command Center bridges them in two passes:

1Pass 1: ICCID Direct MatchThe iPad's eSIM subscription ICCID (from SimpleMDM) is matched directly against the Webbing SIM inventory ICCID. This is the primary match method — instant, no external API calls needed.
2Pass 2: ABM IMEI BridgeFor any remaining unmatched iPads, queries Apple Business Manager for hardware IMEIs and matches against Webbing cellular modem IMEIs. This is the fallback for devices without ICCID data.

📲 Fello Connect — Required Companion App

Fello Connect is Fello's custom iPad companion app that must be installed and running on every deployed iPad. It is the foundation for remote support capabilities.

What Fello Connect Does

  • Enables Screen Sharing — Powers the CoBrowse integration that lets you view and interact with an iPad's screen remotely from the Command Center
  • Reports GPS Location — Sends high-precision GPS coordinates back to the Command Center for the location map in the device drawer
  • Stays in Background — Designed to run silently in the background without interfering with the event app experience
  • Auto-Deployed — Automatically pushed to all iPads during provisioning as the default baseline app
⚠️ Screen Share will NOT work without Fello Connect installed and running on the iPad. If a screen share fails to connect, first verify the app is installed (check 📦 Managed Apps in the drawer), then try Push Apps from MDM Controls to force-install it.

Troubleshooting Screen Share

1Open the Device Drawer for the target iPad
2Check 📦 Managed Apps — verify "Fello Connect" appears in the list
3If missing, click Push Apps in 🔧 MDM Controls to install it
4Ensure the iPad is online (check SIM status is Active and battery > 0%)
5Click 📺 Screen in Quick Actions to launch the session
6If still failing, try 🔄 Restart to reboot the iPad remotely

📝Device Configuration Requests (DCR)

The DCR system bridges client requirements directly into automated device provisioning. Customers submit their iPad configuration needs through a form, and the Command Center auto-provisions the devices.

How the DCR Pipeline Works

1Customer submits DCR formPublic form on the Fello website collects event details, app requirements, WiFi networks, and branding
2Command Center receives submissionSubmission logged to the Requests queue, visible in SimpleMDM → 📋 Requests tab
3Auto-Provisioning Engine triggersAutomatically creates MDM group, assigns apps, generates configuration profiles, and builds custom payloads
4Technician reviews in Provisioning tabVerify matched apps, check warnings, handle any items needing manual setup
5Assign hardware serialsPaste iPad serial numbers to enroll devices into the provisioned group via ABM/DEP

Google Drive Integration

☁️ Files uploaded through the DCR form are automatically sent to a shared Google Drive. Folders are named [Order #] - [Company Name] and organized inside the Fello DCR Uploads Shared Drive.

When a customer submits a DCR with file attachments (wallpapers, credentials, branding):

1Files arrive via the DCR form upload
2Server creates a Drive subfolder: SQ14973 - Acme Corp
3Each file is uploaded to Google Drive with "anyone with link" access
4Drive URLs stored in the submission — visible in the detail modal
5Local temp file is deleted after successful Drive upload

Auto-Provisioning Engine

Navigate to SimpleMDM → ⚙️ Provisioning tab to monitor automated runs.

⚙️ When a DCR is submitted, the provisioning engine automatically runs these steps in the background — no manual action required for standard configurations.

What Auto-Provisioning Does

1Creates SimpleMDM GroupNamed "[Order #] - [Company Name]" with auto-deployment enabled
2Matches & Assigns AppsFuzzy-matches requested app names against the SimpleMDM catalog. Auto-assigns Fello Connect as the baseline.
3Assigns Baseline ProfilesDefault Restrictions + Fello Wi-Fi always applied. Kiosk mode gets Safari Lock profile.
4Generates Custom ProfilesBuilds .mobileconfig XML for: custom WiFi credentials, passcode policies, web content filters, wallpaper payloads
5Matches Home Screen LayoutInspects assigned apps and selects the matching pre-configured home screen layout
6Assigns Serials (if included)Claims device serials via DEP/ABM and moves them into the group

Provisioning Run Statuses

StatusMeaning
✅ SuccessAll steps completed — group created, apps matched, profiles assigned
⚠️ PartialMostly done but some items need manual setup (e.g., app not found in catalog)
❌ FailedProvisioning error — check logs and retry manually
⚠️ If a provisioning run shows Partial, check the Manual Setup Needed list — these items (e.g., Guided Access passcode, custom enterprise apps) must be configured by a technician on each device.
🔄Common Workflows

🔄 Pre-Event: Prepare an Order

1Search the order number e.g., FE13916
2Check Coverage — review auto-generated site check, click Apply on best carrier
3Resume Service — click ▶ Resume Service in sidebar
4Verify — scan fleet table for any Suspended badges
5Pulse — copy generated share link, send to event organizer
6Export — download CSV for warehouse packing checklist

🛑 Post-Event: Decommission Equipment

1Search the order
2Suspend — click ⏸ Suspend Service Prevents idle data charges
3Lost Mode — click 🔴 with return message Secures iPads in transit
4Usage — set dates to rental period, click Calculate
5Export — download billing CSV
6Revoke — kill the Pulse share link

🆘 During Event: Troubleshoot a Device

1Search order or device serial
2Open Drawer — click the device row
3Diagnose: No connectivity → Check SIM Status, Resume if Suspended Wrong carrier → Change Carrier in SIM Controls App issue → Push Apps in MDM Controls Screen frozen → Remote Restart in Quick Actions Need to see screen → Verify Fello Connect is installed, then launch Screen Share via CoBrowse

📊 Billing: Generate a Usage Report

1Search the order in Lookup
2Confirm date range in 📊 Data Usage sidebar card
3Click 📊 Calculate
4Review total GB and active lines
5Click 📥 Export CSV to download
